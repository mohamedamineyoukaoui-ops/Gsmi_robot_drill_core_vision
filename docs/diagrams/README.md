The diagrams show available branches. An individual analysis runs only the selected piece method and requested optional classifiers. Chemistry defaults to A3; the random forest requires an explicit API choice. Stitching uses a 50 px/cm fallback when no robot scale or marker is available; see the [stitching guide](../../pipeline/image_processing/README.md).

## Render a diagram

Requires Node.js/npm. From the **project root**:

```bash
npx -p @mermaid-js/mermaid-cli@12.0.0 mmdc -i docs/diagrams/pipeline_overview.mmd -o docs/diagrams/pipeline_overview.png -b white -s 3 -c docs/diagrams/config.json
```

Replace both input and output basenames to render another diagram. The shared [config.json](config.json) defines typography and flowchart styling; `-b white -s 3` sets the background and rendering scale. Inspect the PNG for clipped labels and readable arrows before committing it.

Architecture illustrations are maintained separately in [docs/architectures/CREDITS.md](../architectures/CREDITS.md). Model result figures are generated by [tools/make_figures.py](../../tools/make_figures.py).
